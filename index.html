📖 Como funciona o Voyager

O Voyager foi criado para que você nunca mais esqueça um item essencial. Veja como é fácil usar:

1. Criar uma Viagem

Clique em "Nova Viagem", defina o destino, as datas e o tipo (Praia, Negócios, etc). O sistema vai gerar automaticamente uma lista base para você.

2. Clima e Assistente IA

Ao abrir a viagem, o Voyager busca a previsão do tempo real. Se vai chover ou fazer calor, o Assistente Inteligente (✨) sugere itens extras (como guarda-chuva ou protetor solar). Clique em "+ Adicionar" para incluir.

3. Organizar Categorias

Você pode criar categorias personalizadas (ex: 🐶 Pet, 🎿 Esqui) clicando no botão no final da lista. Também pode renomear ou excluir categorias passando o mouse no título delas.

4. Compartilhar

Dentro da viagem, clique em "📤 Compartilhar" para gerar um link. Envie para quem for viajar com você. A pessoa poderá importar a viagem inteira para a conta dela com um clique!

5. Instalar no Celular

O Voyager funciona offline no celular. Se estiver no Chrome ou Safari, vá no menu do navegador e escolha "Adicionar à tela de início".

◆ Sobre o Voyager

O Voyager nasceu da necessidade de simplificar o planejamento de viagens. Sabemos que a ansiedade de "será que esqueci algo?" pode atrapalhar a experiência.

Nosso objetivo é unir tecnologia, clima e inteligência artificial para criar listas dinâmicas e personalizadas, para que você só se preocupe em aproveitar a jornada.

Desenvolvido com carinho por Dyona Software Companhi.

🔒 Política de Privacidade

Seus dados são seus.

1. Armazenamento: Suas listas e dados de conta são armazenados de forma segura na nuvem (via Supabase), protegidos por criptografia e regras de acesso (RLS), garantindo que apenas você veja suas viagens.

2. E-mail: Seu e-mail é usado exclusivamente para login, recuperação de senha e comunicações essenciais do sistema. Nunca vendemos ou compartilhamos seus dados com terceiros.

3. Clima: Para exibir a previsão do tempo, enviamos apenas o nome da cidade digitada para a API pública da Open-Meteo. Nenhum dado pessoal seu é enviado.
